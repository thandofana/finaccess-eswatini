# Reference documentation

Phase 2 uses the following World Bank materials:

- Global Findex 2025 Microdata Codebook
- Eswatini DDI/XML metadata, reference `SWZ_2024_FINDEX_v02_M`
- Global Findex and Digital Connectivity questionnaires for interpretation checks

Official catalog: https://microdata.worldbank.org/catalog/7900

Local PDF/XML copies are Git-ignored because the World Bank Microdata Library terms prohibit redistribution without permission. The generated Phase 2 tables retain source URLs and aggregate schema information only.
